# Python If/Else, Loops, Functions

This project contains introductory Python scripts demonstrating conditional statements, loops, and functions.

- **0-positive_or_negative.py**: Assigns a random signed number to `number` and prints whether it is positive, zero, or negative.
- **1-last_digit.py**: Prints the last digit of a random number and describes whether it is greater than 5, equal to 0, or less than 6 and not 0.
- **2-print_alphabet.py**: Prints the ASCII alphabet in lowercase without a newline, using one loop and one print function.
- **3-print_alphabt.py**: Prints the ASCII alphabet in lowercase without `q` and `e`, using one loop and one print function.
- **4-print_hexa.py**: Prints all numbers from 0 to 98 in decimal and hexadecimal using one loop and one print function.
- **5-print_comb2.py**: Prints numbers from 0 to 99 with two digits, separated by `, `, ending with a newline.
- **6-print_comb3.py**: Prints all possible different combinations of two digits in ascending order, separated by `, `, ending with a newline.
- **7-islower.py**: Defines a function `islower(c)` that checks if a character is lowercase using `ord()`- **8-uppercase.py**: Defines a function `uppercase(str)` that prints a string in uppercase followed by a newline, using `ord()` to convert characters.
- **9-print_last_digit.py**: Defines a function `print_last_digit(number)` that prints and returns the last digit of a number.
- **10-add.py**: Defines a function `add(a, b)` that returns the sum of two integers.

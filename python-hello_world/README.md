# Python Hello World
This project contains introductory Python scripts for ALU Higher Level Programming.
- **0-run**: Runs a Python file stored in the environment variable `$PYFILE`.
- **1-run_inline**: Runs Python code stored directly in the environment variable `$PYCODE`.
- **2-print.py**: Prints the string `"Programming is like building a multilingual puzzle"` using the `print` function.
- **3-print_number.py**: Prints the integer stored in the variable `number`, followed by `Battery street`, using f-strings.
- **4-print_float.py**: Prints a float stored in the variable `number` with 2 decimal places, using f-strings.
- **5-print_string.py**: Prints 3 times the string stored in `str`, followed by its first 9 characters, using string repetition and slicing.
- **6-concat.py**: Prints `"Welcome to Holberton School!"` using the variables `str1` and `str2`.
- **7-edges.py**: Prints the first 3 letters, last 2 letters, and the middle of the string `word` using slicing.
- **8-concat_edges.py**: Prints `"object-oriented programming with Python"` by slicing parts of the variable `str` and concatenating them, without using new variables or string literals.

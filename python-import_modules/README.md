# Python Import & Modules

This project demonstrates importing functions and using modules in Python.

- **0-add.py**: Imports the `add(a, b)` function from `add_0.py`, assigns values to `a` and `b`, and prints the result of the addition in the format `a + b = result`.
- **1-calculation.py**: Imports functions from `calculator_1.py` and prints the results of addition, subtraction, multiplication, and division using variables `a = 10` and `b = 5`.
- **2-args.py**: Prints the number of arguments and lists them with their positions using `sys.argv`.
- **3-infinite_add.py**: Prints the sum of all command-line arguments, handling any number of integers (including very large ones).
- **4-hidden_discovery.py**: Imports the compiled module `hidden_4.pyc` and prints all names defined in it, excluding those starting with `__`, in alphabetical order.
